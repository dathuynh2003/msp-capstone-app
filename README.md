# MSP Capstone App

## Giới thiệu

MSP Capstone App (Meeting Support Platform) là một dự án ứng dụng di động được phát triển bằng ngôn ngữ chính là Dart (Flutter) chuyển về quản lí dự án phần mềm cho các Business có hỗ trợ meeting.

## Công nghệ sử dụng

- **Dart** (Flutter): 92.6%
- **C++**: 3.9%
- **CMake**: 2.9%
- **Swift**: 0.3%
- **HTML**: 0.2%
- **C**: 0.1%

## Hướng dẫn cài đặt và chạy dự án

### 1. Clone source code

```bash
git clone https://github.com/dathuynh2003/msp-capstone-app.git
cd msp_app
```

### 2. Cài đặt thư viện phụ thuộc

Sử dụng Flutter để tải các package cần thiết:

```bash
flutter clean
flutter pub get
```

### 3. Chạy dự án

Để chạy ứng dụng trên thiết bị thật hoặc giả lập:

```bash
flutter run
```

Hoặc chọn thiết bị trên VSCode/Android Studio và nhấn "Run".

### 4. Build ứng dụng

- Để build file APK cho Android:

  ```bash
  flutter build apk
  ```

- Để build file IPA cho iOS, bạn cần máy Mac và Xcode:

  ```bash
  flutter build ios
  ```
